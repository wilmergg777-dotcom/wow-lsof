 ASTROIO LAUNCHER — PC Windows y Linux (v4, build 4 / versión 2.4.7)
════════════════════════════════════════════════════════════════

QUÉ ES
------
Un programa chiquito (5 MB) para que los jugadores entren al juego
SIN abrir el navegador a mano y SIN escribir la dirección:

   - Hace doble clic en el icono → abre el juego en una ventana
     limpia (sin pestañas, sin barra de direcciones: modo "app"
     del Edge/Chrome; si no los encuentra, usa el navegador por
     defecto del sistema).
   - Al abrirse comprueba la versión en el servidor igual que la
     APK: si hay launcher nuevo, lo descarga, verifica su SHA-256,
     se reemplaza solo y abre el juego ya actualizado.
   - La dirección del servidor va ofuscada dentro del programa
     (XOR, igual que en la APK): no aparece en texto plano.

NUEVO EN LA v4 (2.4.7): SETUP DE WINDOWS EN GO
----------------------------------------------
El Setup antiguo (NSIS, 249 MB) instalaba un AstroIO.exe con el
manifest SxS roto y Windows mostraba al hacer doble clic:

   "No se pudo iniciar la aplicación: la configuración en
    paralelo no es correcta" (sxstrace.exe)

AHORA el instalador también es Go (launcher/setup/), 100% estático
(sin ningún runtime de C++): ese error es IMPOSIBLE por
construcción. Además pesa ~5 MB en vez de 249 MB y:

   - No pide permisos de administrador (instala por usuario en
     %LOCALAPPDATA%\Programs\AstroIO).
   - Crea los accesos directos en el Escritorio y en el menú
     Inicio, y pregunta si quieres abrir el juego al terminar.
   - Instala el mismo launcher auto-actualizable de siempre.

Si un jugador tiene la versión rota instalada: basta con ejecutar
el Setup nuevo una vez; sobrescribe AstroIO.exe con el bueno.

ARCHIVOS
--------
   main.go                  → código fuente del launcher (una sola
                              fuente para Windows y Linux)
   hidewindow_windows.go    → evita la ventana negra de consola
   hidewindow_other.go      → equivalente para Linux
   go.mod                   → módulo Go (sin dependencias externas)
   build.sh                 → compila launcher Windows/Linux + Setup
                              y muestra los SHA-256 para version.json
   setup/                   → código del instalador Windows en Go
                              (embebe el launcher con go:embed)
   AstroIO-Setup-Windows.exe→ instalador de Windows (lo genera
                              build.sh; se publica en /launcher/)
   instalar-linux.sh        → instalador para Linux (copia a
                              ~/.local/bin y crea el acceso "AstroIO"
                              en el menú de aplicaciones)

CÓMO LO USA UN JUGADOR
----------------------
WINDOWS (instalador):
   1) Descarga AstroIO-Setup-Windows.exe
   2) Doble clic → instala solo (sin admin) y crea los accesos.
      La primera vez puede salir el aviso azul de SmartScreen
      ("Windows protegió tu PC") porque el .exe no está firmado
      con certificado de pago: "Más información" →
      "Ejecutar de todas formas". Solo sale la primera vez.
   3) Desde entonces: doble clic en el icono "AstroIO".
WINDOWS (sin instalar):
   También puede descargarse AstroIO-Launcher-windows.exe y
   ejecutarlo directamente donde quiera.
LINUX:
   1) Descarga AstroIO-Launcher-linux
   2) Opción fácil:  bash instalar-linux.sh  → queda instalado
      como app "AstroIO" en el menú.
      Opción directa: dar permiso de ejecución y abrirlo:
         chmod +x AstroIO-Launcher-linux
         ./AstroIO-Launcher-linux
   3) Requiere algún navegador (Chromium/Chrome/Brave/Edge para
      la ventana en modo app; con Firefox abre en ventana normal).

CÓMO PUBLICAR UNA VERSIÓN NUEVA (para el administrador)
-------------------------------------------------------
1) Edita launcher/main.go → sube launcherVersionCode (+1) y
   launcherVersionName si corresponde.
2) bash launcher/build.sh  → genera launcher Windows/Linux +
   AstroIO-Setup-Windows.exe e imprime los 3 SHA-256.
   (El workflow de GitHub Actions hace todo esto solo en cada
   push que toque apk/ o launcher/.)
3) Sube los 3 archivos por FTP a  /launcher/  del servidor.
4) Sube /apk/version.json REGENERADO por el workflow (lleva los
   SHA-256 reales de los 3 archivos; NUNCA lo edites a mano).
5) Listo: los launchers viejos se actualizan solos al abrirse.

NOTA IMPORTANTE
---------------
Si el jugador NO tiene Internet, el launcher abre el juego igual
(solo fallará la carga de la página, que ya muestra su propio
aviso). La actualización automática se salta en silencio y se
reintentará la próxima vez que abra.
